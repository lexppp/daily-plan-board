# 每日计划台 · v1.2.0

个人每日计划管理。**单文件 HTML，零外部依赖**，双击 `index.html` 就能用，手机可「添加到主屏幕」当 App。
纯本地运行，不联网、不上传任何数据。

> 本目录已于 2026-11-26 从 v2.0.0（乌托邦工作台改造版）**回退到 v1.2.0**（改大版本之前的版本）。

## 功能

| 区块 | 作用 |
|---|---|
| 今天要处理 | 当天到期与逾期的计划，勾选即完成 |
| 明日要处理 | 提前预览明天要做什么 |
| 添加计划 | 标题 / 优先级 / 时长 / 计划日期 / 备注 |
| 计划列表 | 全部计划，可编辑、删除、打卡 |
| 完成率看板 | 今日完成率进度环 + 近 30 天热力图 |
| 周计划板 | 一周七天的日程分布 |
| 每日提醒 | 浏览器通知 + 提示音，可设提醒时间 |
| 消息中心 | 站内小邮箱：未读红点、一键已读、删除已读 |

时长模型：单日 / 一周 / 一月 / 长期，长期任务可每天重复打卡。

## 数据在哪

全部在本机浏览器的 `localStorage`，键前缀 `wb_dailyplan_`：

| 键 | 内容 |
|---|---|
| `wb_dailyplan_tasks` | 所有计划与打卡记录 |
| `wb_dailyplan_inbox` | 消息中心邮件 |
| `wb_dailyplan_reminder` | 提醒设置 |
| `wb_dailyplan_seen_ver` | 已读版本号（版本更新弹窗用） |

**换浏览器 / 清缓存会丢数据**，重要内容请定期用页面里的「导出」备份成 JSON。
