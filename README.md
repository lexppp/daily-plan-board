# 每日计划台 · v2.0.0

个人计划与效率工作台。单文件网页 + 可选云服务同步，手机 / 电脑都能用，可「添加到主屏幕」当 App。

> **数据在哪**：默认存在**你自己浏览器的 localStorage** 里，不上传任何人服务器。
> 想跨设备同步 → 见下方「跨设备同步」。

## 每日计划怎么用

1. 左侧「每日计划」→ **＋新建计划**：填标题、优先级（P0~P3）、时长、日期
   - **单日**：当天做完打勾即可
   - **一周 / 一月**：在开始日到结束日之间，**每天都要打一次卡**
   - **长期**：每天都出现在待处理列表，直到你不再需要
2. **今天要处理**：逾期项自动标红顺延；**明日要处理**：明天到期，也可提前打卡
3. **周计划板**：本周七天分布，点条目直接打卡
4. **每日提醒**：右栏设时间（如 09:00），到点响铃 + 系统通知，
   逾期和 P0 任务自动发到**消息中心**（顶栏红点提示，支持一键已读 / 删除已读）

## 跨设备同步（可选）

1. 打开 `config.js`，确认 `cloud.endpoint` 和 `cloud.publishableKey` 已填
2. 用手机号或邮箱登录
3. 手机和电脑登**同一账号** → 数据实时同步，且只有你能看到（按 `owner_id` 行级隔离）

把这两个值留空 = 纯本地模式，功能不受影响。

## 数据备份

侧栏底部「导出备份」下载 JSON，「导入恢复」还原（不限条数）。
旧版 v1.x 的计划数据会在新版首次打开时**自动迁移**，迁移结果会发一条通知到消息中心。

## 技术约束

- 单文件 HTML，所有 CSS / JS 内联，**不引任何外部框架、CDN 字体或图表库**
- 图表与图标全部是**内联 SVG**
- localStorage key 前缀 `wb_mayday_`
- 云端表名：`plan_tasks` / `todos` / `fitness` / `growth` / `topics` / `drafts` / `kpi` / `spark_runs`

## 已知边界

- 每日提醒只在**页面保持打开**时触发（浏览器不支持后台定时推送）
- 灵感抓取面板只显示跑批缺口，不能直接执行（需要本地 Python 环境）
